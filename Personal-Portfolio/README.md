# Multi-page Personal Portfolio (Week 01 Minor Project)

A beginner portfolio website built with five interconnected HTML5 pages and one shared CSS stylesheet.

## Pages
- `index.html` — Home
- `about.html` — About and education
- `skills.html` — Technical and personal skills
- `projects.html` — Sample projects
- `contact.html` — Contact details and a demonstration form

## Technologies
- HTML5 for page structure and semantic elements
- CSS3 for layout and responsive presentation
- Git for version control
- GitHub for repository hosting

## Run locally
Open `index.html` in a web browser. Keep all six website files in the same folder so the navigation links and stylesheet work.

## Publish with GitHub
1. Create a new GitHub repository, for example `personal-portfolio`.
2. Upload all website files (`index.html`, the other four HTML files, and `style.css`).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Important sample-data note
All names, college details, email address and project descriptions are fictional examples. Replace them with accurate information before submitting. The contact form is only a front-end demonstration; it does not send messages without a backend or form service.
